Learning by building.

Each project here started as an experiment: a captcha engine, an AI chat app, a handful of network and RF case studies. Most of them are still running today.

I care about speed, readable code and small surfaces. If something here is useful to you, email is the fastest way to reach me.

  • BackendPython, FastAPI and Flask on Render and Vercel serverless.
  • FrontendSemantic HTML, modern CSS and vanilla JavaScript.
  • Security & ResearchHMAC and SHA-256 hashing, network telemetry and RF metrics analysis.
  • Deployment & DNSVercel, Hurricane Electric DNS, GitHub Actions and hybrid mail routing.

Three colours, three languages.

Every page here is plain HTML, CSS and JavaScript. No frameworks. The three accent colours belong to those three languages; tap one to repaint the site.

HTML

Structure

HTML is the skeleton of every page: headings, links, buttons and forms. Tim Berners-Lee created it in the early 1990s.

Here it builds the nav, project cards, calculator keys and game boards.

CSS

Style

CSS controls how everything looks: colours, layout, animation and responsive design. It was proposed in 1994 by Håkon Wium Lie.

Here it draws the dark theme, the moving strip, the hover effects and the phone layout.

JavaScript

Behaviour

JavaScript makes pages interactive. Brendan Eich wrote the first version at Netscape in 1995 in about ten days.

Here it runs the fidget spinner, calculator, SHA-256 tool, password generator and all five games.
